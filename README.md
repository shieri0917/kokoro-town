# こころタウン

30歳前後の女性が、自分のペースで前に進むための相談アプリです。
AI（ローカルで動くWebLLM）とおしゃべりしながら、セルフケアや人生設計を進められます。

## 特徴

- **完全ローカル動作**：会話・記録データはすべてこの端末（ブラウザ）の中だけに保存され、外部には送信されません。AIモデルもブラウザ内でダウンロード・実行されます（初回のみモデルダウンロードで通信します）。
- **相談チャット**：こころおばけ・ここうさ・きぬの3匹が話し相手。気分がいい日は聞き返し（逆質問）で会話を広げます。
- **自分ペース宣言**：「〇歳までに〇〇しなきゃ」というべき論を深掘りして、自分のペースを言葉にします。
- **強み発見チャット**：自分の強みが分からないときに、一緒に言語化します。
- **じぶん設計**：なりたい自分の1行保存、ライフマップ（キャリア/お金/恋愛/健康/自分自身）、過去の自分との比較、逆算した一言、同世代のリアルな声。
- **セルフケア**：深呼吸ガイド、5-4-3-2-1グラウンディング、体調メモ（睡眠・生理周期・気になること）。
- **ごほうび**：相談やセルフケアを続けると、ポイント・レベル・バッジ・ご褒美カードが手に入ります。
- **データの書き出し・取込み**：設定画面からJSONファイルとしてバックアップ・復元できます。
- **クライシス対応**：つらい言葉が入力されたときは、公的な相談窓口（こころの健康相談統一ダイヤル、いのちの電話）を自動で案内します。

## 使い方（iPhoneで使う場合）

このアプリはPWA（Progressive Web App）として作られているので、GitHub Pagesなどで公開したURLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」をするとアプリのように使えます。

### GitHub Pagesで公開する手順

1. GitHubアカウントを作成する（無料）：https://github.com/join
2. このフォルダ（`kokoro-town`）の内容を、新しいリポジトリにアップロードする
   - GitHubのウェブ画面から新規リポジトリを作成し、"Add file" → "Upload files" でこのフォルダの中身をアップロードするのが簡単です
3. リポジトリの Settings → Pages を開く
4. "Branch" を `main`（またはアップロードしたブランチ）、フォルダを `/ (root)` に設定して Save
5. 数分待つと、`https://(ユーザー名).github.io/(リポジトリ名)/` のURLが使えるようになります
6. iPhoneのSafariでそのURLを開き、共有ボタン → 「ホーム画面に追加」

### 注意点

- 初回起動時、AIモデル（1.5GB前後）のダウンロードが行われます。Wi-Fi環境での初回起動をおすすめします。
- ダウンロード済みのモデルはブラウザ内にキャッシュされ、以降はオフラインでも動作します（Safariの「サイトデータを消去」をするとキャッシュも消えるので注意してください）。
- iPhoneでWebGPU（AIの高速化技術）を使うには iOS 26 以降が必要です。iPhone 17であれば標準で対応しています。

## ローカルで動作確認する場合

ブラウザの `file://` から直接開くと、AI機能やService Workerが正しく動かないことがあります。簡易HTTPサーバーを立てて確認してください。

```powershell
# このフォルダ(kokoro-town)で実行
python -m http.server 8000
```

その後、`http://localhost:8000/` をブラウザで開きます。

## フォルダ構成

```
kokoro-town/
├── index.html          画面のマークアップ
├── style.css           見た目（水色×緑の町テーマ）
├── manifest.json        PWA設定
├── sw.js                Service Worker（オフライン対応）
├── assets/              キャラクター画像・生成スクリプト
└── js/
    ├── storage.js        データ保存・書き出し/取込み
    ├── knowledge.js       AIへの指示文・相談窓口情報・エピソード集
    ├── chat.js            チャット（WebLLM連携）
    ├── gamification.js    ポイント・バッジ・ご褒美カード
    ├── lifedesign.js      じぶん設計（なりたい自分・ライフマップ等）
    ├── selfcare.js        セルフケア（深呼吸・グラウンディング・体調メモ）
    └── app.js             全体の画面遷移・結線
```

## データについて

すべてのデータはブラウザの localStorage に保存されます。他の端末に引っ越す場合や、ブラウザのデータを消してしまいそうなときは、設定画面の「書き出す（バックアップ）」でJSONファイルを保存しておき、新しい環境で「取り込む（復元）」から読み込んでください。
